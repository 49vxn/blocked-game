## Decisions

- **Build our own skill.** Research found no dominant high-star
  before-compaction skill: the high-star repos are ambient-memory systems, the
  handoff tools are small, and Freebuff documents no lifecycle hooks. A tail
  skill would have to be adapted anyway. `[V]` sources below; `[?]` star
  estimates for small repos.
- **Deterministic collector, model-written judgment.** The script records
  commands, exits, counts, listeners, files, tasks and workspaces; the agent
  writes decisions, blockers and next actions. This follows the evidence that
  summaries lose literal details (paths, SHAs, errors) while structured state
  preserves continuation.
- **`[V]` / `[?]` tags and binding blocker tuples.** A handoff must preserve
  what was verified now and what is only recalled; blockers keep STOP,
  requires, authority and fallback instead of becoming caveats.
- **One runtime source of truth.** `docs/STATE.md` owns runtime; `HANDOFF.md`
  links to it; `tasks/README.md` owns work status. This fixes the repeated
  PID/test-count drift.
- **Chain-numbered sessions.** `docs/compaction/sessions/YYYY-MM-DD-NN.md`,
  never edited after the fact; the index points at the latest.
- **Claude Code gets a pointer, not a copy.** `.claude/skills/before-compaction/`
  is a thin entry point to the canonical `.agents` skill; duplicating the
  procedure would create two sources of truth.
- **No automatic Freebuff hook.** Freebuff has no documented PreCompact hook,
  so the skill is manual at ~85% context; `scripts/before-compaction.ts collect`
  is the fallback.
- **The collector is read-only by default.** `--build` is opt-in because a build
  rewrites `dist/` and can change what a live server serves; typecheck and the
  suite do not mutate game artifacts.
